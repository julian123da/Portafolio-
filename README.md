# Portafolio Web – Julian Acevedo

Este repositorio contiene mi **portafolio web personal**, desarrollado como proyecto final del proceso de formación en **Campuslands**.  
El objetivo del proyecto es presentar mis habilidades técnicas, proyectos realizados y experiencia académica de forma profesional y accesible para reclutadores.

 **Portafolio en línea:**  
 https://julian123da.github.io/NOMBRE_DEL_REPOSITORIO/

---

## Descripción del proyecto

El portafolio es una aplicación web **responsive**, diseñada para adaptarse correctamente a dispositivos móviles, tablets y computadoras de escritorio.  
Cuenta con una estructura clara, navegación intuitiva y un diseño moderno enfocado en la experiencia del usuario.

En él se pueden encontrar:
- Información personal y perfil profesional
- Experiencia académica
- Proyectos desarrollados durante el entrenamiento
- Enlaces a repositorios de GitHub
- Contacto directo vía correo electrónico

---

## Tecnologías utilizadas

- **HTML5** → Estructura semántica del sitio  
- **CSS3** → Diseño, layout, animaciones y responsive design  
- **JavaScript** → Interacciones básicas  
- **Font Awesome** → Iconografía  
- **Git & GitHub** → Control de versiones  
- **GitHub Pages** → Despliegue del proyecto  

---

## Responsive Design

El sitio fue desarrollado siguiendo principios de **responsive design**, asegurando una correcta visualización en distintos tamaños de pantalla.

Se utilizaron:
- Flexbox
- Grid
- Media Queries
- Unidades relativas

Optimizado para:
- Dispositivos móviles  
- Laptops y pantallas grandes  

---

## Navegación del sitio

El portafolio cuenta con las siguientes secciones:

- **Inicio:** Presentación personal y enlaces a redes profesionales  
- **Experiencia:** Formación académica y procesos de aprendizaje  
- **Proyectos:** Proyectos desarrollados con descripción y enlaces al código  
- **Contacto:** Redirección directa al correo electrónico  

La navegación es clara e intuitiva mediante un menú superior.
